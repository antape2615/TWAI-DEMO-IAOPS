# IAOPS Frontend

Frontend moderno para la plataforma IAOPS construido con React, TypeScript, Vite y TailwindCSS.

## 🚀 Stack Tecnológico

- **React 18** - Framework UI
- **TypeScript** - Type safety
- **Vite** - Build tool y dev server
- **TailwindCSS** - Utility-first CSS
- **React Router** - Routing
- **React Hook Form** - Formularios
- **Axios** - HTTP client
- **Zustand** - State management
- **Lucide React** - Iconos

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Copiar variables de entorno
cp .env.example .env

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Preview de build
npm run preview
```

## 🔧 Configuración

Editar `.env`:

```env
VITE_API_URL=http://localhost:8000
```

## 📁 Estructura

```
frontend/
├── src/

```
